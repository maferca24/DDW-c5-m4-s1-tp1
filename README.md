# [Nombre del proyecto: DDW-c5-m4-s1-tp1 ]

## Qué es
Página de Presentación personal resolviendo consigna TP N1

## Cómo correrlo
pnpm install
pnpm run dev

## Uso de IA
- Herramientas que usé (gemini,  Kiro).
- Me ayude con IA en un principio para encarar el proyecto de acuerdo a lo que tenia armado, según el tp,  habia armado  base estructura, instalación de tailwind, lista de habilidades e importación de componentes, luego tambien lo ulicé para crear estilos con tailwind y para resolver errores,  utilice tambien Kiro para resolver una linea porque no tomaba el tema y no renderizaba la pagina.

## Lo que me costó

En un principio no podia instalar los paquetes, salian varios errores en la consola, lo solucione consultando gemini.
Encarar el proyecto de acuerdo a lo visto.
